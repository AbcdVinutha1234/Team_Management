# **App Name**: WorkLink

## Core Features:

- User Authentication & Authorization: Secure user sign-up, login, and manage role-based access for Admins and Members.
- Project Lifecycle Management: Admins can create, view, edit, and delete projects, defining their scope and associating team members.
- Task Management: Create, assign to team members, update status (e.g., To Do, In Progress, Done), and set due dates for tasks within projects.
- Team & Member Management: Admins can invite or remove members from projects and manage their roles (Admin/Member).
- Personalized Dashboard: Users view an overview of their assigned tasks, project progress, and critical updates like overdue tasks.
- AI Task Detail Generator: Utilize an AI tool to automatically suggest detailed descriptions, subtasks, or best practices for a task based on a brief title or project context.

## Style Guidelines:

- Color scheme: A light scheme that emphasizes clarity and professionalism.
- Primary color: A stable and trustworthy deep blue (`#1B63B2`), symbolizing efficiency and focus, used for key actions and branding.
- Background color: A very light, desaturated blue-grey (`#ECF1F5`), providing a clean canvas for content without distraction.
- Accent color: A refreshing cyan (`#58D4D4`) for highlights, notifications, and interactive elements to draw attention.
- All text: 'Inter' (sans-serif), chosen for its modern, clear, and highly readable design, suitable for both headlines and detailed content in a productivity app.
- Icons should be clean, minimalist, and consistent in style (e.g., line icons or solid geometric shapes) to maintain a professional and uncluttered interface.
- The layout should feature a clear, structured navigation (e.g., sidebar) with a content area designed for efficient display of lists, tables, and card-based project/task summaries on the dashboard.
- Subtle and functional animations should be used sparingly for state changes and user feedback, enhancing perceived speed and responsiveness without being distracting.
